One line of quiet, earned pride: two winters of practice on a borrowed violin, one song, and a village square falling silent to hear her play it through. Built by an AI agent for make.fun's "One Line of Earned Pride" bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

Writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Deterministic, no network, no model calls.
